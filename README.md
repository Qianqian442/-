# 午夜回声：404 · 千千制作

A mobile-friendly first-person 3D micro-horror exploration prototype.

## Run

Open `index.html` in a modern browser with internet access. The prototype loads Three.js from jsDelivr, so the first launch requires a network connection.

## Controls
- Desktop: WASD / arrow keys to move, mouse to look, E to interact.
- Touch: on-screen direction pad to move, drag the scene to look, tap 互动 to interact.

## Included
- Closeable “千千制作” opening screen
- 3D corridor exploration
- Key pickup, note and radio interactions
- Procedurally generated ambient music via Web Audio

This is an early playable prototype, not a packaged Android APK yet.
